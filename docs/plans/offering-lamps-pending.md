# 祈福供灯仍待确认

这一页是内部记录，不是已经审定的法律条款，也不是前台承诺。

## 已确认的商业范围

每次由顾客在天下第一财神庙和灵隐寺中选择一处供灯。单次 USD 50 和年包 USD 300 / 12 次都是每次一处，不含两处。中英文页面写同一句话。拟定日期是每月 1 日。USD 300 是全年总额，不是每月收取，也不自动续费。预约和支付未开放。

## 仍未核实

- 由谁供灯。
- 从哪一个月开始，以及遇到关闭日怎么办。
- 灯的数量和点亮多久。
- 现场照片或视频里的人，是顾客还是执行的人。页面不要求顾客上传照片。记录只在画面中的本人同意后私密交付。不收集姓名、愿望或证件。

## 退款草案

这不是公开的“任何情形都不退”。也没有把这项服务假定成定制服务所以一律不退。

- 执行前取消，以及年度里尚未执行的部分，规则仍待确认。
- 已经实际执行的部分，原则上不退。
- 未履约、无法履约、重复扣款，以及法律强制的退款权利，是例外。
