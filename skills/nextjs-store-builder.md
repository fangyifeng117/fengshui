# nextjs-store-builder

> 这是 2026-11-23 根据本仓库已经执行的约束整理的说明，不是技能原件。来源是父侧转述的既有技能规则，以及 `AGENTS.md`、`TEMPLE-STORE-SPEC.md` 里标为既有技能约束的部分。不要把它当成用户原话，也不要用它打开支付或索引。

## 产品页

十个模块的 DOM 顺序固定，不重排、不在中间插入新段：

1. breadcrumb
2. gallery
3. title、price、primary action
4. benefit bullets
5. trust badges
6. specs
7. practical use
8. fixed disclaimer
9. FAQ
10. related products

后来的内容映射进最接近的现有模块。用户稿里的溯源、视频、尺码、物流、评论和祈福说明，在没有单独批准换序之前，不另做第三套顺序。

当前展示：

- 商品画廊保留模块，用文字占位，不渲染各 SKU 样品图，不留空盒。
- 首页原有三格可以放三张主题参考图：屋檐、木珠串、灯火。木珠串必须写成风格示意。这三张不进入商品图库。
- 不展示商品价格，不用 0 元或免费代替。
- 不提供加购入口。价格和图片字段留在数据模型里。
- 公开 Product JSON 不带图片，也不带 Offer 金额。
- 无授权时不写 `Presented at`。不虚构评论、销量或寺院授权。

桌面可以保持画廊与标题区左右排列。标题区不显示价格。

## 结账与数据

支付保持关闭。结账按钮必须与真实行为一致：不可付款时写明支付已关闭，不做成可付款的样子。不接入新的支付商，不写入密钥。

购物车行可以留在 httpOnly cookie 里，便于只读文件系统上的演示。公开购物车和订单 JSON 不带金额。

## 不做的事

不启用索引，不提交 sitemap，不加载营销像素，不发信。不把 M2–M7 的数据库、对象存储、邮件或广告做成可营业功能。不使用佛像或“大雄宝殿”。没有授权的原片不上站。
